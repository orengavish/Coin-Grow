What Is Coin Grow?

Core idea

Kids learn money concepts by living them — bartering in a medieval market, making choices, facing real consequences.

The prompt is the product

Claude AI generates all lesson content: story, characters, branching paths, outcomes. The game engine is just a delivery vehicle.

Social layer

Classrooms compete. Schools compete. Future: market simulator for investment competitions.

8+
Target age
Lesson 1 — The Orange Quest

Technology Stack

Game engine

Flutter + Flame

Flutter for all UI (menus, dialogue, debrief). Flame for the 2D game world (sprites, paths, camera, collisions).

Character animation

Rive

Skeletal animation + state machines. Used by Duolingo. Prof Penny will be a Rive rig.

Content engine

Claude AI (Anthropic)

Generates lesson JSON from prompts. Every scene, character, choice, and consequence is AI-written.

Backgrounds

AI-Generated (DALL-E 3)

Bing Image Creator — free. Cartoon storybook style. Ken Burns animation applied in Flutter.

Character sprites

Kenney.nl (CC0)

Free, professional sprite sheets with walk cycles. No attribution needed. Drop-in to Flame.

State / Nav

Provider + Go Router

Lesson state machine already built. Zone-based: intro → pathSelect → pathScenes → ending.
