The Matrix — Possibility Space

Before the AI generates anything, the junior defines the axes. The matrix tells the AI what exists in this world.

Barter lesson — 3 dimensions
📍 Locations — where Eli can go
📦 Items — what's being traded
🧑 Characters — who lives there
Junior picks active combinations

Not every intersection needs content. Junior marks which cells are active — mandatory (must visit) or optional (side quest).

AI fills the cells

Once matrix is defined, Claude writes every NPC's dialogue, motivation, and trade offer. Junior doesn't write a word of dialogue.

Mandatory — must visit
Optional — side quest
Empty cell

Matrix → Flame World

Each active matrix cell becomes a zone in the level. Junior sets axes. AI generates content. Flame renders it.

🔄 Different lesson, different matrix. Lesson 2 (Money) uses time_period × trust × community — completely different axes, same builder.
🧑‍💻 Junior's job: fill in the matrix UI before generation. AI does the rest — dialogue, art prompt, NPC placement.
📍 path_x from the matrix location tells Flame exactly where to place each NPC on the game world coordinate.

Quest System

Every level has mandatory quests (story) and optional quests (exploration). Matrix cells become quests.

✅

Mandatory Quests

Required to complete the lesson. Drive the main story. Always 1–3 per level. Awarded base points.

📌 Get the orange from the orange seller
→ 100 pts · lesson complete
⭐

Optional Quests

Never required. Player discovers them by exploring. Each optional quest awards bonus points + a badge. May unlock a hidden scene.

🌊 Explore the river → talk to fisherman
→ +25 pts · badge: River Explorer 🗺️
🌳 Visit the apple farm → trade chain
→ +50 pts · badge: Chain Trader 🔗
Quest UX in the game
📋 Mandatory — shown in HUD as active objective
🔍 Optional — discovered when player enters NPC zone (not pre-announced)
🏅 Completion — badge notification + score flash
📊 End screen — all quests, badges earned, points breakdown
